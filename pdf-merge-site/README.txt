אתר איחוד קבצי PDF
===================

בתיקייה הזו יש קובץ אחד: index.html. זה כל האתר.

להעלאה לאתר קבוע וחינמי (GitHub Pages):
1. פותחים חשבון חינמי ב-github.com
2. יוצרים מאגר חדש (New repository), בשם למשל pdf-merge, מסוג Public
3. לוחצים Add file > Upload files וגוררים את index.html, ואז Commit changes
4. נכנסים ל-Settings > Pages, בוחרים Branch: main ותיקייה root, ושומרים
5. אחרי דקה-שתיים הקישור מוכן: https://שם-המשתמש.github.io/pdf-merge/

להעלאה ל-Netlify (קבוע, אחרי הרשמה חינמית):
1. נרשמים ב-netlify.com
2. נכנסים ל-app.netlify.com/drop וגוררים את התיקייה
3. מתחברים לחשבון כדי לשמור את האתר (אחרת הוא נמחק אחרי שעה)

חשוב: אתר שהועלה בלי הרשמה נמחק אחרי כשעה.
